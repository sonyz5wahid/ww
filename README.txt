Wahid Word - editor dokumen bergaya Word untuk Android 4.2+.
Dokumen disimpan di folder "Dokumen" (penyimpanan internal), format .docx.
Font bawaan aplikasi: Carlito (setara Calibri), Liberation Serif/Sans/Mono (setara Times New Roman/Arial/Courier New),
Caladea (setara Cambria). Semuanya berlisensi SIL OFL dan diunduh saat build.
Pintasan: Ctrl+S/Shift+S simpan, O buka, N baru, Z undo, Y redo, B/I/U, L/E/R/J perataan, F/H cari-ganti.
